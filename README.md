# 🍽️ Restaurant Ordering System & POS Web App

An interactive, responsive Restaurant Ordering System designed for point-of-sale (POS) and dine-in management. This application provides real-time food category filtering, dynamic cart calculations with tax auto-computation, custom item instructions, and real-time clock synchronization.

## ✨ Key Features

* **Dynamic Category Filtering:** Instantly filter food items across categories (*Main Courses*, *Fast Food*, *Desserts*, or *All Menu*) with automatic item counter updates.
* **Interactive Cart & Order Details:** Real-time quantity updates (`+` / `-`) for individual food items.
* **Automatic Subtotal, Tax & Total Calculation:** Dynamically computes subtotal, applies a 10% tax rate, and updates the final checkout amount.
* **Custom Item Notes & Special Instructions:** Clickable modal popups allowing customers or staff to add custom notes (e.g., "extra spicy", "no onions") to specific items.
* **Live Date & Time Sync:** Displays real-time order timestamps using native JavaScript `Date` APIs.
* **Modular Code Structure:** Clean separation of data array models (`products.js`) and application logic (`Menu.js`) utilizing ES6 `import`/`export` syntax.

## 🛠️ Built With

* **HTML5:** Semantic structural layout and modal overlays.
* **CSS3:** Custom grid layout, flexbox, custom scrollbars, and styled backdrop-filter blur effects.
* **JavaScript (ES6+ Modules):** DOM manipulation, array higher-order functions (`filter`, `reduce`, `find`), event delegation, and interval timer integration.
